# Saathi agent instructions

- At the start of every Saathi task, use the `$saathi-maintainer` skill. If skill discovery is unavailable, read and follow [.agents/skills/saathi-maintainer/SKILL.md](.agents/skills/saathi-maintainer/SKILL.md) directly.
- Start with the [AI wiki index](AI-Wiki/Home.md) and [project conditions](AI-Wiki/Project-Conditions.md). Read the relevant design notes and recent work log before changing behavior.
- Keep the wiki in Git. Before handing off substantive work, update the affected notes and append a brief work-log entry. Record confirmed standing instructions from project maintainers in the relevant wiki note so future agents can apply them. Preserve the scope of one-off requests.
- Work within the current request. Commit, push, publish, or deploy only with explicit authorization for that action.
